# 批量视频去水印

为哔哩工具姬提供本地视频固定区域去水印功能。

## 功能

- 批量选择本地视频
- 从指定时间生成视频预览
- 在预览画面中拖动框选水印区域
- 保存并复用水印区域预设
- 浅色文字或图标会从多帧画面检测稳定笔画，并使用 FFmpeg `removelogo` 精细蒙版处理
- 彩色或实心水印使用 FFmpeg `delogo` 处理整个框选区域
- 后台串行处理队列、进度显示与取消
- 默认保留原视频，并在原目录生成 `_delogo.mp4`

去水印会使用邻近像素填补水印区域，无法恢复从未出现在视频中的真实像素。浅色文字模式通常比整框处理保留更多原始背景。

## 本地开发

该插件依赖包含 `media` API 的 BiliToolkit 主程序分支。先启动主程序，再在本目录运行：

```powershell
pnpm install
pnpm dev
```

随后在哔哩工具姬中将当前开发地址加载为测试插件。
