# 视频下载

## 项目简介

[哔哩工具姬](https://github.com/hzhilong/bilitoolkit) 插件。

下载视频、音频、弹幕、字幕、封面等资源（仅支持UP主上传的视频）。

> **说明：** 本插件仅支持下载 UP 主发布的普通视频及相关资源，不支持付费课程、番剧、电视剧、电影、纪录片等受限制内容的下载。使用者应确保对所下载内容具有合法访问权限，并遵守相关法律法规、版权规定及平台用户协议。
